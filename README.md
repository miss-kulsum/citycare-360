# CityCare 360 demo

A small frontend-only hackathon prototype for hospital coordination and biomedical waste pickup workflows.

## Run

1. Keep `index.html`, `style.css`, and `app.js` in the same folder.
2. Open `index.html` in Chrome, Edge, or Firefox.
3. Click **Start 30-sec demo** to walk through records, pickup, and reports.

No install or build step is needed. All records are sample data and stay in page memory. The hero photo and web fonts load from the internet; the page keeps a colored background if the image cannot load.

## Demo interactions

- Add a waste record or request a pickup.
- Change pickup status in the queue.
- Search sample records with `CC-2401`, `CC-2402`, or `CC-2403`.
- Change the demo role, use the care assistant, and download sample report data as CSV.

This prototype does not connect to a hospital, store patient data, or provide medical advice.
